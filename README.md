# game-dictionary
Game Dictionary

A beginner-friendly Python project that demonstrates how to use dictionaries to store game information in Python.

📌 Description

This project creates a dictionary containing details about a game, such as the game name and game type. It also shows how to access values using the get() method.

 Concepts Used

Python Dictionaries
Key-Value Pairs
get() Method
Data Storage

💻 Code

games = {
    "name": "minecraft",
    "game type": "sandbox",
}

print(games.get("name"))

▶️ Output

minecraft
